# Forex LSTM Classification (PyTorch)

This repository contains a compact, runnable example to design, train and evaluate a small LSTM neural network for forex price action classification (Buy, Sell, Hold) based on Smart Money Concepts (SMC) strategy.

Key points:
- PyTorch-based LSTM classifier predicting next action from previous sequence of OHLCV prices
- Data: OHLCV data from MetaTrader 5 (MT5) for multiple timeframes (M15, H1, H4)
- Advanced training: early stopping, learning rate scheduling, L2 regularization, gradient clipping
- Includes preprocessing (MinMax scaler), sequence creation, comprehensive training loop with checkpointing
- Smart defaults: automatically detects prepared datasets, uses best practices for NN training

Files added:
- `requirements.txt` — minimal Python deps (now includes MetaTrader5)
- `forex_lstm/data.py` — data loading & preprocessing helpers (MT5 integration)
- `forex_lstm/model.py` — LSTM classifier model
- `forex_lstm/train.py` — training CLI
- `forex_lstm/evaluate.py` — evaluation CLI + metrics
- `forex_lstm/utils.py` — dataset and helper utilities
- `download_data.py` — script to batch download data for multiple symbols/timeframes
- `consolidate_data.py` — script to consolidate all downloaded data into a single dataset
- `DATA/` — folder where downloaded MT5 data is saved as CSV files

Contract (inputs/outputs):
- Input: MT5 symbol (e.g., 'EURUSD') with timeframe and bars, or CSV with OHLCV columns
- Output: saved model checkpoint and scaler file; evaluation prints accuracy and confusion matrix

Quick start (Windows PowerShell):

1) Ensure MetaTrader 5 is installed and running with a demo/live account
2) Create a venv and install deps

```powershell
python -m venv .venv; .\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

3) Download data for multiple symbols and timeframes

```powershell
python download_data.py --symbols EURUSD GBPUSD USDJPY --timeframes M15 H1 H4 --bars 10000
```

4) Consolidate all data into a single dataset

```powershell
python consolidate_data.py --wide-format
```

5) Train the LSTM model (automatically uses prepared datasets)

```powershell
python -m forex_lstm.train
```

**CUDA-Optimized Training:**
- **Mixed Precision**: Automatic FP16 training for 2x speed and memory efficiency
- **GPU Memory Management**: Configurable memory fraction usage
- **Optimized Data Loading**: Pinned memory, multiple workers, prefetching
- **Multi-GPU Support**: Automatic DataParallel for multiple GPUs
- **CUDA Benchmarking**: Optimized cuDNN settings for faster training
- **Comprehensive metrics**: Tracks train/val loss & accuracy, learning rate

**Default Training Configuration:**
- Epochs: 100 (with early stopping)
- Hidden size: 128
- Layers: 2
- Dropout: 0.2
- Batch size: 64
- Learning rate: 0.001 (with scheduling)
- Weight decay: 0.0001

To customize training:

```powershell
# Quick training with custom settings
python -m forex_lstm.train --epochs 50 --hidden 256 --lr 0.0005

# GPU-specific settings
python -m forex_lstm.train --device cuda --gpu-memory-fraction 0.9 --mixed-precision

# CPU training (for systems without GPU)
python -m forex_lstm.train --device cpu --mixed-precision false

# Use specific dataset
python -m forex_lstm.train --ticker "my_dataset.csv"

# Download fresh data
python -m forex_lstm.train --ticker EURUSD --timeframe H1 --bars 5000
```

6) Evaluate

```powershell
python -m forex_lstm.evaluate --checkpoint checkpoints/ckpt_epoch10.pt --ticker "consolidated_dataset.csv"
```
